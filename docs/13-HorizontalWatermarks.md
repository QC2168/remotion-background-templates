# 第 13 个背景：斜向滚动文字水印

Composition ID 保留 HorizontalWatermarks。既有 12 个背景保持不变。本版已通过用户验收。

- 视频：1920×1080、30 fps、12 秒 / 360 帧、无音轨 H.264 MP4。
- 背景 #161616，文字 #3a3a3a；DIV 与 AI工程师-DIV 均为 30px、800 字重，共享同一字体样式，无额外缩放，完整内容为 DIV AI工程师-DIV。
- 标签旋转 -30°，Alibaba PuHuiTi 3 Bold 字体，留白与错位排列。
- 从右上到左下移动，每周期位移 (-486,280)px，方向约 29.95°，总速度约 46.74px/s。
- 沿基线重复周期 (486,-280)px，标签间隔 (243,-140)px，相邻行偏移 (50.4,87.2)px，实际垂直于文字基线的行距约100.72px，比上一版125.90px减少20%，平铺扩至29行，隔行交替长短标签。
- Remotion frame 驱动，360 帧循环，首尾平移相差完整重复周期。

render-watermarks.mjs 渲染，verify-diagonal-motion.mjs 验证实际组件位移，qa-watermarks.py 检查实际视频并生成联系图和 JSON。
