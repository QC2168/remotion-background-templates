# 第 13 个背景：水平滚动文字水印

Composition ID：`HorizontalWatermarks`。保留现有 12 个背景的内容、顺序、默认参数与 6 秒时长。

- 输出：1920 × 1080，30 fps，12 秒 / 360 帧，无音轨 H.264 MP4。
- 底色 `#161616`，文字 `#3a3a3a`；`DIV`（40px）与 `AI工程师-DIV`（30px）交错，表达 `DIV AI工程师-DIV`。
- 单个标签旋转 -30°，粗体 Alibaba PuHuiTi 3；旋转仅作用于标签。
- 同类横向间距 280px，列间纵向错位 17px，同类行距 218px，相邻行横向错位 126px；长标签相对短标签偏移 (40,109)。

使用 `node scripts/render-watermarks.mjs` 单独渲染。使用 `python scripts/qa-watermarks.py` 检查输出并生成联系图和 JSON 记录（依赖 Pillow、NumPy）。
